`checksums.txt` records exact SHA-256 values for the checksum-bound sanitized
result artifacts listed there. Those files retain their historical release bytes
and are not regenerated by `analysis/`. In contrast,
`publication_bundle_manifest.json` and `publication_checks.json` describe the
current repository release bundle: its exact-byte integrity hash is separate
from calculation-level reproduction, because Pillow PNG rendering is not
cross-platform byte-identical.
